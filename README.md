# marketing-campaign-customer-engagement

Analysis of campaign acceptance, customer spending, purchasing activity, and engagement using SQL, R, and Power BI.

## Data Source

[View marketing_campaign.csv on Kaggle](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis?select=marketing_campaign.csv)

## Repository Contents

- [R analysis script](Customer_Analysis.R): Data cleaning, KPI calculations, visualisation, and exploratory complaint modelling.
- [SQL analysis script](Customer_Analysis.sql): Data validation and KPI queries.
- [Dashboard screenshot](dashboard.png): Power BI dashboard preview.
